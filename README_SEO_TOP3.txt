- Páginas de serviços: residenciais, comerciais, transporte de móveis, urgentes e fim de semana

- Botões WhatsApp automáticos via `assets/js/site-config.js`

## Passo rápido (obrigatório) — Google Business
1) Abra `assets/js/site-config.js`
2) Substitua:
   - `googleBusinessReviewUrl` pelo link oficial do Google "Deixar avaliação"
   - (opcional) `googleMapsUrl` com o link do Google Maps
3) Publique o site no Hostinger / GitHub Pages
